# 🌟 SunnyWay Wendy | Professional Services Website

> *Bringing warmth and professionalism to every interaction*

**SunnyWay Wendy** is a modern, elegant web presence designed to showcase premium services with a welcoming, professional touch. This responsive website demonstrates mastery of frontend development while maintaining a beautiful, conversion-focused design.

## 🎯 About This Project

This is a beautifully crafted service-based website featuring Wendy's professional offerings. The project showcases essential web development skills including **responsive design**, **user experience optimization**, and **modern web standards**.

### 📖 What's Included

- **🏠 Home Page** - Captivating landing section with hero imagery and call-to-action
- **📋 About Section** - Professional background and credentials
- **🎨 Gallery** - Visual showcase of work and services
- **💼 Services** - Comprehensive service offerings with detailed descriptions
- **📞 Contact** - Easy-to-use contact form for inquiries

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Scylla-spec/sunnyway-wendy.git

# Navigate to the project directory
cd sunnyway-wendy

# Open in your default browser
open index.html
```

Or simply **drag `index.html` into your browser** — no build tools required!

### Development

```bash
# For local development, you can use a simple HTTP server
python -m http.server 8000
# Then visit: http://localhost:8000
```

## 🔧 Customization Guide

### Update Content
1. Edit HTML files directly to update text content
2. Replace image files in the `images/` folder
3. Modify colors in CSS files

### Add New Services
```html
<!-- Add to services.html -->
<div class="service-card">
    <h3>Your Service</h3>
    <p>Description here</p>
    <button>Learn More</button>
</div>
```

### Modify Styling
```css
/* Edit css/styles.css */
:root {
    --primary-color: #your-color;
    --secondary-color: #your-color;
}
```
